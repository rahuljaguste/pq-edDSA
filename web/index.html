Prove you control an Ed25519 key — without revealing it

A zero-knowledge proof of the R_det relation from Post-Quantum Readiness in EdDSA Chains (FC 2026), on Binius64.

Your seed never leaves this page. The proof is generated here, in WebAssembly, on your machine. There is no server to send it to: this page is static files, and after the module loads it makes no network requests at all — open DevTools → Network and watch. That is the entire point. A proving service that asks for your seed offers no privacy, whatever else it promises.
Research proof of concept. Use throwaway keys only. This is unaudited software carrying 96-bit classical soundness — the ceiling upstream Binius64 currently exposes, and below the ~128 bits you should want in production. The zero-knowledge property has not been audited either. Do not paste a seed that controls anything you care about.
